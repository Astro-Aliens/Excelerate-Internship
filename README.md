# 🧹 Work 3 – Data Cleaning

The following cleaning steps were performed:

### ✅ Duplicate Handling

* Checked for duplicate records
* Removed duplicate rows where necessary

### ✅ Missing Value Assessment

Missing values were identified and reviewed across all columns.

### ✅ Text Standardization

* Removed leading spaces
* Removed trailing spaces
* Standardized categorical values

### ✅ Date Formatting

Converted date-related columns into proper datetime format:

* Learner SignUp DateTime
* Opportunity Start Date
* Opportunity End Date
* Apply Date
* Date of Birth
* Entry Created At

### ✅ Blank Value Handling

* Blank strings converted to NULL values
* Missing text fields handled appropriately

# ✅ Work 4 – Data Quality & Validation

Data validation checks included:

### Data Consistency Checks

* Opportunity Category validation
* Status Description validation
* Country value consistency
* Gender value consistency

### Record Validation

* Duplicate verification
* Missing value assessment

### Quality Observations

The dataset was found to be largely consistent and suitable for analysis.
